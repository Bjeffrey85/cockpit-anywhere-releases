

# Cockpit Anywhere: downloads

Working cockpit panels for Microsoft Flight Simulator 2024 on your phones, tablets and screens.

**[Download the latest version](https://github.com/Bjeffrey85/cockpit-anywhere-releases/releases/latest)**

1. Download `Cockpit-Anywhere-<version>-Windows.zip` from the latest release.
2. Unzip it anywhere and run `Cockpit Anywhere.exe`.
3. Start a flight in MSFS 2024, then scan the QR code in the top right with your phone or tablet.

The app checks this page once at launch and tells you when a new version is out. It never downloads
or installs anything by itself.

To update: close Cockpit Anywhere, unzip the new version over the old folder (or anywhere), and run it.
Your settings are kept.
